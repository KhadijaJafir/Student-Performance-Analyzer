# Student Performance Analyzer

A beginner-friendly data analysis project built with Python to analyze student academic performance.

## Project Overview

In this project, I analyzed a dataset containing student information, subject scores, attendance, average scores, and performance categories.

The purpose of this project was to practice data loading, exploration, analysis, visualization, and interpretation using Python.

## Objectives

- Load and explore student performance data.
- Analyze overall and subject-wise performance.
- Identify the highest- and lowest-performing students.
- Analyze student performance categories.
- Examine the relationship between attendance and average scores.
- Create visualizations to identify patterns in the data.
- Summarize the key findings from the analysis.

## Technologies and Tools

- Python
- Pandas

## Dataset

The dataset contains the following information:

- Student ID
- Student Name
- Python score
- Database score
- Statistics score
- Attendance
- Average score
- Performance category

## Analysis Performed

I performed the following analysis:

- Inspected the dataset shape and columns
- Checked data types
- Calculated the class average
- Identified the highest-performing student
- Identified the lowest-performing student
- Calculated subject-wise averages
- Counted students in each performance category
- Calculated the correlation between attendance and average score
- Created multiple visualizations
- Interpreted the results

## Visualizations

The project includes visualizations for:

- Average score by subject

- Distribution of student average scores

## Key Findings

- The overall class average was **78.57**.
- **Zainab** had the highest average score at **95.33**.
- **Hamza** had the lowest average score at **58.33**.
- Database and Statistics had the highest subject averages.
- Attendance and average score showed a very strong positive correlation of approximately **0.99**.
- Most students were classified as **Excellent**.
- Only one student was classified as **Needs Improvement**.
